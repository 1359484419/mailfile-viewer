メールファイルをブラウザでそのまま開く

.msg・.eml・winmail.dat・.pst・.ost・.olm・.mbox を閲覧・変換できます。処理はすべてお使いの端末内で行われ、メールがアップロードされることはありません。

ファイルは端末から出ません・アップロードなし・追跡なし

できること

  • 単体メール（.msg・.eml）やメールボックス全体（.pst・.ost・.olm・.mbox）を、フォルダー・検索・添付ファイル付きで閲覧。
  • winmail.dat／ATT00001.dat を開いて、中に埋もれた本来の添付ファイルを取り出す。
  • 標準形式へ変換：EML（ZIP まとめ）、Thunderbird や Apple Mail で読める MBOX、メール一覧 CSV、連絡先 CSV、ブラウザの「PDF として保存」による PDF。
  • フォルダー内の添付ファイルを ZIP で一括ダウンロード。

日本語メールへの対応

ISO-2022-JP（JIS）、Shift_JIS、EUC-JP、UTF-8 の件名・本文・添付ファイル名をデコードします。古い .msg や winmail.dat ではファイル内に記録されたコードページを使って文字化けを防ぎます。CSV は Excel で文字化けしないよう BOM 付き UTF-8 で書き出します。

プライバシー

このサイトは静的ファイルのみで構成され、サーバー側の処理はありません。アクセス解析やトラッキングのスクリプトも入っていません。HTML メールはスクリプト無効のサンドボックス内で表示し、外部画像は許可するまでブロックします。

Pro 版（準備中）

現在の機能はすべて無料です。数 GB 規模の PST のストリーミング処理や PDF 一括出力などを Pro 版として予定していますが、まだ販売はしていません。

よくある質問

Outlook や Microsoft 365 は必要ですか？
不要です。Windows・Mac・Linux・Chromebook のブラウザで動作します。
どのくらい大きなファイルを開けますか？
ファイル全体をメモリに読み込むため端末次第です。一般的なノート PC なら 1〜2 GB 程度、スマートフォンでは数百 MB が目安です。
パスワード付き PST は開けますか？
暗号化・パスワード保護された PST には対応していません。
