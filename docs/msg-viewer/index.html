Open .msg files without installing anything

Drop a .msg file to read it, save the attachments, or convert it to .eml or PDF. The file stays on your computer.

Files stay on your device · no upload · no tracking

About .msg files

A .msg file is a single email, meeting request or contact that someone dragged out of Outlook for Windows. Inside it is an OLE “compound file” — a little file system holding MAPI properties for the sender, recipients, body and each attachment. Mac and Linux mail apps cannot read it, which is why people end up with “I can’t open this attachment” problems when a colleague forwards a message as an attachment.

This viewer reads the compound file directly. It shows the HTML body when there is one, falls back to the plain-text body, and if the message was only stored as compressed RTF it decompresses the RTF and extracts the original HTML or text.

Converting MSG to EML

Click Save .eml to get a standards-based copy you can open in Apple Mail, Thunderbird or any mail client. The converter writes a proper MIME message: sender, recipients, date and subject headers (UTF-8 encoded where needed), both plain-text and HTML alternatives, inline images and every attachment. Messages that are attached to the .msg are turned into nested .eml files.

MSG to PDF

Use Print / PDF and choose “Save as PDF” in the print dialog. The printout includes a header block (from, to, cc, date, attachment names) followed by the message body. Remote images are left out so the PDF is created without contacting any server.

MSG questions

The body is empty or garbled — why?
Some very old .msg files store text in a legacy code page. The viewer uses the code page recorded in the file; if it is wrong, please report the problem (without sending the file) using the link that appears with the error.
Can I open .oft templates?
Templates use the same container format and usually open, but this is not tested extensively.
