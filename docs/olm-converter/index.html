What is inside an .olm file

An .olm export is a ZIP archive. Each message is stored as a small XML document (subject, addresses, sent time, HTML body and an attachment list) and attachments sit next to it as ordinary files. Because it is not a mailbox format that other programs read, the usual advice is to re-import it into Outlook — which does not help if you no longer have a Mac with Outlook.

This converter reads the ZIP directory directly and only decompresses what it needs, then maps the XML into regular messages with folders.

OLM to MBOX or EML

  • MBOX: one file per export; Apple Mail (File → Import Mailboxes) and Thunderbird import it directly.
  • EML (.zip): one .eml per message, grouped by folder — good for archiving or for uploading to another mail service.
  • CSV: a spreadsheet overview for searching or legal review.

Limits

Calendar, contacts, notes and tasks inside the OLM are not converted yet — only mail. Very large exports (several GB) need a desktop browser with enough memory.
