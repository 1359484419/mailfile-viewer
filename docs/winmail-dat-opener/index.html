Open winmail.dat and get your attachments back

Received a mysterious winmail.dat or ATT00001.dat? Drop it here to see the message and download the files hidden inside.

Files stay on your device · no upload · no tracking

Why you got a winmail.dat

When an Exchange or Outlook user sends mail in “Rich Text” format, the server wraps the formatting and the attachments in a container called TNEF (Transport Neutral Encapsulation Format) and attaches it as winmail.dat. Apple Mail, Gmail, Thunderbird and most phones do not understand TNEF, so the recipient sees one useless .dat file instead of the PDF or spreadsheet that was actually sent.

What this opener extracts

  • All attached files with their original long file names, including names with accents or non-Latin characters.
  • The message body — plain text, HTML, or HTML recovered from compressed RTF.
  • Embedded messages (an email attached inside the TNEF) which you can open with one click.
  • Subject, sender and date when the sender’s server included them.

If you received the whole email as a .eml file with winmail.dat inside, open the .eml: the winmail.dat shows up as an attachment with an Open button.

How to stop receiving winmail.dat

The fix is on the sender’s side: ask them to send in HTML or plain-text format instead of Rich Text, or their administrator can set the remote domain’s TNEF setting to off. Until then, this page lets you read what they send.

winmail.dat questions

Does it work on iPhone and Android?
Yes. Save the winmail.dat attachment to Files, open this page in Safari or Chrome and choose the file. Downloads go to your Files / Downloads folder.
The winmail.dat only contains formatting, no files
That happens: some TNEF attachments carry only the rich-text body. The viewer then shows just the message text.
