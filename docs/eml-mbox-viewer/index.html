Read .eml files and MBOX mailboxes

Open saved .eml messages or whole .mbox files (Thunderbird, Apple Mail, Google Takeout) to read, search and export them — privately, in your browser.

Files stay on your device · no upload · no tracking

EML files

An .eml file is the raw internet message: headers, then MIME parts for text, HTML and attachments. The viewer decodes quoted-printable, base64 and encoded-word headers in any charset (including ISO-2022-JP and Shift_JIS), shows inline images, and lists every attachment. The Headers tab shows the original header block — useful for checking where a suspicious message really came from.

MBOX files

MBOX stores many messages in one text file separated by “From ” lines. Google Takeout exports Gmail this way. Open the .mbox to browse it as a list, search by sender or subject (optionally in message bodies), save single messages as .eml, export the list to CSV, or pull out all attachments as a ZIP.

EML / MBOX questions

My Google Takeout mbox is several gigabytes
Large files are read into memory; a desktop browser with 8 GB+ RAM handles about 1–2 GB comfortably. Split bigger files first.
Are scripts in HTML emails executed?
No. Messages are shown in a sandboxed frame with scripts disabled and a strict content security policy.
