Privacy and how it works

Short version: your files never leave your device, and this site does not track you.

Files stay on your device · no upload · no tracking

Local processing

MailFile Viewer is a set of static files (HTML, CSS and one JavaScript bundle) hosted on GitHub Pages. When you choose a file, the browser’s File API gives the page the bytes and the parsers run in the same tab. There is no upload endpoint and no backend at all. After the page has loaded you can go offline and keep working.

No tracking

The site includes no analytics, advertising or third-party scripts, sets no cookies and does not use local storage for your mail. Fonts are system fonts. The hosting provider (GitHub) may keep standard server logs of page requests, as for any website; those logs never include your files.

Safe display

HTML email is rendered in a sandboxed frame with scripts, forms and plugins disabled and a content security policy that blocks network access. Remote images stay blocked unless you click “Load remote images” for that message, which prevents tracking pixels from reporting that you opened it.

Open source

The code is MIT-licensed. Parsing uses these open-source libraries: pst-extractor (MIT) for PST/OST, @kenjiuno/msgreader (Apache-2.0) for MSG, postal-mime (MIT-0) for EML, fflate (MIT) for ZIP, fast-xml-parser (MIT) for OLM XML. The TNEF and RTF decoders are written from Microsoft’s published open specifications [MS-OXTNEF] and [MS-OXRTFEX].

Reporting problems

If a file fails to open, the error message has a link that pre-fills a GitHub issue with the error code and your browser version only. Please never attach private email to a public issue.
