Files stay on your device · no upload · no tracking

What you can do

  • Read a single saved message (.msg, .eml) or a whole mailbox archive (.pst, .ost, .olm, .mbox) with folders, search and attachments.
  • Unpack winmail.dat / ATT00001.dat and get the real attachments out.
  • Convert to standard formats: EML files in a ZIP, an MBOX mailbox for Thunderbird or Apple Mail, a CSV list of messages, a contacts CSV, or a PDF through your browser’s “Save as PDF”.
  • Download every attachment of a folder at once as a ZIP.

How private is it?

The page is a static site. When you pick a file the browser reads it into memory and the parsers run in this tab — there is no server that receives your mail, no analytics script and no third-party tracker. Remote images inside messages are blocked until you allow them, so opening an old newsletter does not ping the sender. You can disconnect from the internet after the page has loaded and it still works. Details on the privacy page.

Questions

Do I need Outlook or a Microsoft 365 subscription?
No. The file formats are read directly by open-source parsers running in your browser. It works on Windows, macOS, Linux and ChromeOS.
How large a file can I open?
The whole file is loaded into the browser’s memory, so the practical limit depends on your device: around 1–2 GB on a typical laptop with Chrome, Edge or Firefox, and a few hundred MB on phones and tablets. Very large PST files are best split first.
Can it open password-protected PST files?
No. Encrypted or password-protected PST files are not supported and the tool will tell you so.
What happens to embedded messages?
An email attached inside another email (or inside winmail.dat) shows an “Open” button and opens as its own message.
